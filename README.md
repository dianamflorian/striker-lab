# STRIKERLAB // Monochrome Sports Analytics

An interactive sports analytics web application built with **React**, **TypeScript**, and **Vite**. Features a high-contrast monochrome editorial interface with dynamic accent theming tailored to elite athletes.

## Key Features
- **Dynamic Athlete Switcher:** Real-time CSS variable theming adapting colors to each player (Erling Haaland, Jude Bellingham, Gianluigi Donnarumma).
- **Scroll-Driven Modular Assembly:** Progressive `clip-path` and 3D floating transitions synced with vertical scroll depth.
- **Cosmic AR Background:** Pure CSS perspective grids, gravitational wave ripples, aurora nebulas, and orbital ball trajectories.
- **Glassmorphic Navigation:** Translucent sticky header using `backdrop-filter`.

## Tech Stack
- React 19 + TypeScript
- Vite
- Modern CSS3 (Custom Properties, Keyframe Animations, 3D Transforms)
